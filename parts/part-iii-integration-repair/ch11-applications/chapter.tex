\begin{definition}[Admissible Reconstruction]
A reconstruction \(x\in\stateSpace\) is admissible if it is consistent with observations in \(\observationSpace\) and satisfies all active hard constraints in \(\constraintSet\).
\end{definition}

\section{Core Objectives}
\begin{itemize}
  \item Survey domains: vision, robotics, scientific modeling, and distributed systems.
  \item Specify problem templates where reconstruction dominates prediction.
  \item Outline implementation pathways for autonomous agents and program synthesis.
\end{itemize}
