\chapter*{Notation Guide}
\addcontentsline{toc}{chapter}{Notation Guide}

\begin{itemize}
  \item \(\stateSpace\): latent state space.
  \item \(\observationSpace\): observation space.
  \item \(\constraintSet\): active set of constraints.
  \item \(\admissibleSet\): admissible subset of states.
  \item \(\projection\): projection map from latent states to observations.
  \item \(\reconstruction\): reconstruction operator induced by observations and constraints.
  \item \(\repairOp\): repair operator for constraint reconfiguration.
\end{itemize}
